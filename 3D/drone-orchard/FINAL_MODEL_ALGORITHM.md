# 无人机农业生产路径规划最终模型说明

## 1. 项目定位

本项目面向“无人机辅助农业生产”的三维仿真与路径规划展示，目标是在果园、梯田等农业场景中，根据无人机状态、任务目标、气象环境和路径可跟踪性，为多架无人机自动分配任务并生成可执行航迹。

## 2. 最终算法链路

最终采用的模型链路为：

```text
GPR 三维动态气象代价地图
  -> Mamba 无人机动态个体画像
  -> MAPPO 多智能体任务分配与路径策略选择
  -> weather_grid / weather_3D 气象感知路径生成
  -> Robust MPC 航迹跟踪验证
  -> Web 三维可视化展示
```

## 3. 各模块作用

### GPR 三维动态气象代价地图

使用高斯过程回归（Gaussian Process Regression, GPR）根据稀疏气象观测点生成空间、时间和高度相关的气象代价地图。

气象地图包含：

- 风速
- 风向
- 温度
- 湿度
- 天气类型
- 综合气象代价 `cost`

该模块用于告诉路径规划器：哪些区域、哪些高度、哪些时间段飞行风险或能耗更高。

### Mamba 无人机动态个体画像

使用 Mamba 风格状态空间模型处理无人机历史飞行时序数据，生成无人机个体状态画像。

主要输出包括：

- 动态健康分 `dynamic_health_score`
- 风险等级 `dynamic_risk_level`
- 预测平均电流
- 预测电压下降
- 稳定性风险

该模块用于区分不同无人机的能力差异，让状态更好的无人机承担更复杂或更高风险任务。

### MAPPO 多智能体任务分配

使用 MAPPO 作为 MARL（多智能体强化学习）的具体实现，用于完成多架无人机与多个任务目标之间的协同分配。

它解决的问题是：

```text
多架无人机从不同起点出发
+ 多个农业任务目标点
-> 自动判断哪架无人机执行哪个任务
```

### weather_grid / weather_3D 路径生成

任务分配完成后，路径生成模块根据气象代价地图生成航迹：

- `weather_grid`：二维气象网格路径规划，适合固定飞行高度。
- `weather_3D`：三维气象路径规划，支持不同高度层之间切换。

路径代价通常由以下部分组成：

```text
total_cost = distance_cost
           + alpha * weather_cost
           + beta * altitude_change_cost
           + gamma * battery_cost
```

### Robust MPC 航迹跟踪

Robust MPC 用于验证高层规划出的航迹是否能被底层控制器稳定跟踪。

它输出：

- 平均跟踪误差
- 最大跟踪误差
- 控制能耗
- 约束违反次数

该模块让系统不仅能“规划路径”，还能判断路径是否适合真实无人机执行。

## 4. 当前网页可视化内容

当前 Web 页面用于展示：

- 现代平原果园场景
- 高山梯田水稻场景
- 多架无人机起点和终点设置
- 无人机飞行动画
- 不同高度层的风速和风向
- 后续可接入自动任务分配和算法输出航迹

## 5. 后续接入建议

建议第一步接入稳定版本：

```text
weather_aware_assignment
+ weather_grid_path / weather_3D_path
+ GPR weather cost map
+ Mamba UAV profile
```

等前端交互稳定后，再接入 MAPPO checkpoint 做完整多智能体策略展示。
